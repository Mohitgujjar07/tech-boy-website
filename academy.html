Explore Workshop Curricula

Transparent, battle-tested syllabi structured for rapid comprehension and high-retention learning.

01

Foundations & The Neural Leap

Python vectorization, classical ML intuition, backpropagation visualized, and moving from shallow networks to Deep Learning.

02

NLP & The Transformer Revolution

Tokenization, dense vector embeddings, the Attention mechanism, and how Large Language Models (LLMs) read and generate human thought.

03

Multimodal Generative AI & RAG

Prompt engineering patterns, Gemini API multimodal integration (text + image + audio), and Retrieval-Augmented Generation (talking with private PDFs/docs).

04

Autonomous Agentic AI & Capstone

Tool use & function calling, multi-agent collaboration (planning, memory, reflection), and shipping an autonomous web agent capstone.

01

Microcontroller Essentials & Circuit Safety

ESP32 / Arduino pinouts, breadboard prototyping fundamentals, GPIO logic, and avoiding short circuits.

02

Sensors & Real-Time Environment Ingestion

Interfacing ultrasonic, temperature/humidity, and motion sensors with serial monitor debugging.

03

Wireless Telemetry & MQTT Networking

Connecting ESP32 to Wi-Fi, lightweight pub/sub MQTT protocols, and sending telemetry to the cloud.

04

Live IoT Dashboard & Hardware Capstone

Switching physical relays over the internet and building a live browser dashboard to monitor and control the room.

01

Network Anatomy & Packet Forensics

TCP/IP handshakes, DNS inspection, and visually capturing and analyzing network traffic using Wireshark.

02

Web Vulnerabilities & OWASP Top 3

Hands-on demonstration of SQL Injection, Cross-Site Scripting (XSS), and session hijacking in controlled lab environments.

03

Defensive Hardening & Identity Security

Cryptographic hashing vs. encryption, password cracking defense, two-factor authentication mechanics, and system firewall rules.

04

Live Gamified Mini-CTF (Capture The Flag)

Students compete in teams to patch vulnerabilities, crack safe challenges, and earn ethical hacking victory points.

01

Smart Data Processing & Analysis

Modern dynamic spreadsheets, structured data cleanup, and Python automated data wrangling with zero repetitive manual effort.

02

Visual Integration Pipelines (n8n / Webhooks)

Connecting forms, spreadsheets, and databases using webhooks and event-driven automation.

03

Document AI & Automated Parsing

Using LLM vision and APIs to automatically extract data from unorganized invoices, receipts, and messy PDFs directly into structured tables.

04

Enterprise Auto-Pilot & WhatsApp/Email Bots

Building a production automation agent that reads incoming inquiries, generates smart responses, updates tables, and dispatches WhatsApp alerts automatically.
