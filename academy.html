Detailed Roadmap

Explore Workshop Curricula

Transparent, battle-tested syllabi structured for rapid comprehension and high-retention learning.

01

Python & Mathematical Intuition for AI

Vectorized computing with NumPy, data manipulation using Pandas, gradient descent concepts explained visually, and Jupyter environment setup.

02

Computer Vision & Handwriting OCR

Image processing with OpenCV, contour extraction, feature mapping, and building a handwriting OCR ingestion engine similar to real college exam evaluation.

03

Multimodal LLMs & Gemini API Integration

Prompt engineering, token economics, multimodal vision queries, streaming responses, and building an automated student assistance bot.

04

Production Deployment & Capstone

Packaging AI models into FastAPI web endpoints, deploying to lightweight cloud instances, and live student demo presentations.

01

Microcontroller Architecture & Pinout Safety

ESP32 dual-core internals, GPIO pin safety, analog-to-digital conversion (ADC), pulse-width modulation (PWM), and breadboard wiring discipline.

02

Sensors & Actuator Protocols

Interfacing DHT22 temperature sensors, ultrasonic rangefinders, infrared tripwires, relays, and OLED displays over I2C and SPI buses.

03

MQTT Cloud Telemetry & Networking

Connecting microcontrollers to Wi-Fi, publishing telemetry payloads to HiveMQ/EMQX cloud brokers, and handling network reconnect fallbacks.

04

Live Web Dashboard & Hardware Capstone

Building a live real-time dashboard on mobile and web to view dials, trigger physical buzzers, and deploy an automated campus environment node.

01

TCP/IP Architecture & Wireshark Forensics

Deep-dive into network layers, packet sniffing, dissecting HTTP vs HTTPS handshakes, detecting ARP spoofing, and understanding port scanning mechanisms.

02

Web Security & OWASP Top 10 Vulnerabilities

Hands-on lab simulations of SQL Injection, Cross-Site Scripting (XSS), Broken Object Level Authorization, and remediation strategies in code.

03

Reconnaissance & Defensive Hardening

Ethical penetration testing tools (Nmap, Burp Suite), firewall rules, zero-trust network principles, and secure server configuration.

04

Capture The Flag (CTF) Challenge

A high-energy team CTF competition where students audit a deliberately vulnerable test application and submit defensive patches to win.

01

Modern Dynamic Arrays & Formula Mastery

XLOOKUP, FILTER, UNIQUE, SORT, INDEX/MATCH, and nested conditional logic to build responsive financial and student attendance ledgers.

02

Power Query ETL Automation

Connecting disparate CSV and Excel files, automating messy row transformations, merging student lists, and 1-click refreshes that replace manual work.

03

VBA Macros & Automated Batch Invoicing

Writing clean VBA scripts to generate personalized PDF grade reports, send batch emails, and clean corrupt tabular exports with single shortcut keys.

04

AI-Powered Python + Excel Pipelines

Using openpyxl and Python to bridge cloud database queries directly into beautifully formatted Excel spreadsheets for administrative management.
